# Provenance and redistribution

The adapter logic and behavioral test cases derive from the user-supplied accepted
reference under inputs/reference, supplied for this task as behavioral evidence.
Its recorded 15 Node tests and 45 browser checks are historical evidence only.
The package uses a renamed generic adapter, original template/CSS, and a new native
paused composition clock. No private reference font bytes, logos, artwork or
standalone reference index.html were copied. System font stacks require no font
redistribution. The generic demo is explicitly synthetic, not a fictional catalog
or a live delivery claim. No external imagery is required by this abstract alert.

For each generated creator output record: brand-guide source and interpretation,
font source and redistribution permission (if used), local asset attribution,
resolved config and actual validation. Do not assume that access grants a license.

The native RAF engine is intentionally not HyperFrames-compatible. The reference
used a different animation engine; only event-interface expectations are shared.
